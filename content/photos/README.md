# Фото Михаила для статей

Кладите сюда свои фото (jpg, лучше по горизонтали, 1200–2000 px по ширине) и по строке на каждое в `photos.csv`:

```
file,description
prised-shtanga.jpg,Михаил приседает со штангой в Hammer Fit Континент, вид сбоку
vypady-klient.jpg,клиент делает выпады с гантелями, Михаил страхует
```

Агент сам выбирает подходящее фото на обложку и может вставить его в текст. Если своего фото по теме нет, берёт фото с Pexels (нужен ключ `PEXELS_API_KEY`) и подписывает автора.
Подойдут и кадры из Reels: стоп-кадр в хорошем качестве.
