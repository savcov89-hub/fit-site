# Местный контекст: Новосибирск, клуб, истории Михаила

Агент берёт отсюда местные детали для статей. Всё, что здесь записано, проверено Михаилом. Чего здесь нет, того в статье быть не должно.

## Правила
- В статье 1–2 местные детали, и только там, где они помогают понять тему: пример из зала, сезон, условия клуба. Если к теме ничего не подходит, местных деталей нет совсем.
- Брать только факты и истории из этого файла. Не выдумывать клиентов, имена, возраст, сроки, килограммы, отзывы, цифры по погоде.
- Историю клиента пересказывать без имени и узнаваемых деталей: «ко мне пришла девушка после вторых родов», а не «Анна, 34 года».
- Местная деталь не превращается в рекламу: без «приходи в клуб», «запишись», без цен.
- Цифры и выводы по-прежнему из исследований. История Михаила — пример, а не доказательство.
